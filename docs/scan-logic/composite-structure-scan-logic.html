Scanner 作为协作器，聚合 5 个 part（tcpscan / ratelimit / httpProbe / fingerprint / AssetStore）并通过连接器协作

复合结构图 (Composite Structure Diagram) — 结构性图形。展示分类器（如类/组件）的内部结构：部件(part)、端口(port)与连接器(connector)。

PARTS

5 个部件

  • • p_tcpscan — TCP 探测引擎
  • • p_rate — 限速器
  • • p_http — HTTP 探测
  • • p_fp — 技术栈指纹
  • • p_store — 资产存储接口

CONNECTORS

协作流

  • • tcpscan 开放端口 → httpProbe 探测 → fingerprint 识别
  • • 探测结果与 webinfo 经 p_store 落库
  • • ratelimit 在 TCP 与 HTTP 两条路径限流
