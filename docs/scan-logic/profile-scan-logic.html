定义扫描领域的构造型(stereotype)并扩展到 UML 元类，再应用到 Atlas 实际模型元素

剖面图 (Profile Diagram) — 结构性图形。定义一组构造型（ stereotype）以扩展 UML 元模型，用于特定领域建模。

STEREOTYPES

6 个构造型

  • • «Scanner» → Class（编排器）
  • • «Target» → Instance（IP / 域名）
  • • «Port» → Property（带 State 字段）
  • • «Asset» → Class（ES 资产文档）
  • • «Probe» → Behavior（探测行为）
  • • «Store» → Component（资产存储）

APPLICATION

映射到代码

  • • «Scanner» ⇒ Scanner 结构体
  • • «Target» ⇒ task target 字符串
  • • «Port» ⇒ 端口 Asset.State 字段
  • • «Asset» ⇒ model.Asset（_id 前缀判别）
  • • «Probe» ⇒ httpProbe / tcpConnect
  • • «Store» ⇒ ESAssetStore
