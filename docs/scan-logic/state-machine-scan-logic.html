端口探测状态机

单端口从「未知」经 TCP/HTTP 探测进入 open / closed / filtered 等终态，按 shouldPersist 落库

状态机图 (State Machine Diagram) — 行为性图形。描述对象状态随事件迁移的规则。

STATES

7 个状态

  • • Unknown — 探测前初始态
  • • Open — 连接成功并取到 banner
  • • Closed / Filtered / Open|Filtered / Unfiltered / Timeout
  • • Persisted — 经 shouldPersist 判定后落库（双框=终态）

PERSIST

落库策略

  • • open 始终写入 ES（确认资产）
  • • filtered 类受 RecordFilteredPorts 控制
  • • closed / timeout 受 RecordClosedPorts 控制
  • • 域名路径端口缺 State 字段（待补）
