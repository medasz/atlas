HOST PATH

scanHost 三分支

  • • IPv6 → connect 降级（raw 不支持）
  • • IPv4 raw 模式 → SYN/ACK 整块抓包，失败回退 connect
  • • connect 模式 → 逐端口 goroutine + banner + httpEnrich
  • • 全程 panic recover，单目标不拖垮 worker

DOMAIN PATH

scanDomain

  • • 仅探测 commonHTTPPorts 上的 HTTP(S)
  • • httpProbe + fingerprint 回填标题/技术栈
  • • 落库域名资产与端口资产
  • • 已知 gap：端口 Asset 未写 State（待补）
